# Performance

**World-worker inlining budget, 2026-10-24 (source change; takes effect after `npm run build` and a restart):** world processes now start with TurboFan inlining budgets of 11,040 cumulative and 22,080 absolute bytecode bytes (V8 defaults 920 and 4,600), beside the existing 64 MiB semi-space (`WORLD_V8_OPTIONS` in `cluster.ts`). The deep world-field queries (`sdf` → column → `fbm2`/`value2`) exhausted the default budget, leaving the noise helpers as real calls whose double arguments and results were heap-allocated. Sampled allocation in the 192-participant Meridian fixture falls from 5,815 to 4,471 KiB per tick (−23%): `rawColumn` 1,224→657 KiB and `fbm2` 270→82 KiB, while `value2`, `ridge2` and `fade` (182/181/39 KiB) leave the top sites. Genuine objects remain (`roadAt` 421→426, `Math.hypot`'s argument array 365→368). V8 options cannot change JavaScript results; every compared run retains its planet's state hash (`artifacts/lagopt-alloc-{default,inline12x}.heapprofile`).

The lean fixed-tick fixture (`artifacts/lagopt-ab-harness.ts`, `lagopt-abmulti.mjs`) uses the simulation profiler's setup and state hash without its stage wrappers or CPU sampler, runs one bundle under both option sets in rotating rounds, and measures 1,200 ticks after a 600-tick warmup. With 191 bots and a human observer in each planet's first city, mean tick work falls 9.357→8.875 ms on Meridian (−5.2%), 8.157→7.737 on Cinder (−5.1%) and 7.802→7.373 on Nacre (−5.5%); p95 falls 16.44→15.70, 14.60→13.95 and 13.47→13.13 ms, and 11 of 12 paired rounds improve. With 192 bots and no human, the means fall 8.784→8.207 (−6.6%), 6.994→6.863 (−1.9%; Cinder pairs +0.1/+0.8/−6.3%) and 7.197→6.828 ms (−5.1%). World construction is 5–13% faster and the 600-tick warmup changes by −8% to +2%. Code space grows from about 4–6 to 5–10 MiB; RSS stays about 600 MiB. Total process CPU per tick, including compiler and GC threads, changes by −2% to +5%, so the gain is on the simulation thread that owns the 16.67 ms budget. Earlier sweeps found 2× mixed, 3–5× between −2% and −8% depending on the session, 12× and 20× consistently −4% to −6%, and no added benefit from doubling the per-function limit (`lagopt-inline-budget-sweep{1,2}.jsonl`, `lagopt-inline-confirm-{1337,7331,20077}.jsonl`, `lagopt-inline-confirm-bots-only-*.jsonl`).

## Limits

These fixtures have 15 AI players, no connected browsers, and no live persistence or network traffic. A lower average tick cost alone does not establish that capacity or sustained real-time stability.
