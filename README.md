# THE MMOFPS

Latest update: the campaign now assigns separate squad operations across the map, responds to threatened holdings and remote footholds, and supplies ground transports in every city and harbor. Each planet targets up to 192 participants and reduces distant bot reserves under sustained load. Captures take 60 seconds per stage, and a first conquest on each planet earns 150 salvage. G and M use cleaner, cheaper tactical cartography; O shows conquest contracts and campaign dispatches. See [campaign behavior and verification](docs/CAMPAIGN.md). Protocol 28. [Renewable xenolite gathering](docs/RESOURCES.md) funds persistent camps.

A browser FPS built around a large, connected frontier: cities, wilderness, caves, railways, ferries, aircraft, ground vehicles and gunboats. Open the URL and join the Terran Accord, Helix Combine or Vanguard Pact at random, beside a friendly staging base. No initial faction menu is required; the in-game atlas lets you change allegiance later.

The complete client, server and shared world/movement code are in `packages/client`, `packages/server` and `packages/shared`. Build and verification tools are in `scripts`; server setup is described in [DEPLOY.md](DEPLOY.md).

## Run locally

Requires Node.js 22.11 or newer. Start/test scripts enable the built-in SQLite module (experimental in Node 22.11).

```sh
git clone https://github.com/Zelaron/mmofps-engine.git
cd mmofps-engine
npm ci
npm run build
npm start
```

The repository is private, so Git needs your GitHub credentials when cloning. Open **http://localhost:8080** after startup. `npm run dev` rebuilds the client and server while editing.

The build downloads the two versioned Barlow fonts and verifies their SHA-256 checksums. `npm run assets` can fetch them separately; subsequent builds reuse the verified cache. All other game models and textures are generated from source. Dependencies, downloaded font binaries, built bundles, saved worlds and diagnostic captures are excluded from Git. The dependency lockfile and third-party license texts are included.

Run `npm run check` for type checking and the automated tests. Browser checks additionally need `npx playwright install chromium` (on a Linux machine missing browser libraries, use `npx playwright install --with-deps chromium`). `npm run test:browser` expects a local game at port 8081 or the URL in `GAME_URL`; the specialized scenery/resource fixtures create their own isolated worlds. Performance documents refer to local `artifacts/` captures, which are not part of the repository and can be regenerated with the documented scripts.

`npm start` launches a gateway and three separate world processes: Meridian, Cinder and Nacre. Each has the complete world, including cities, caves, vehicles and scheduled transport. Different seeds produce different terrain and underground layouts; city names also differ. One command runs the whole cluster locally, and workers can use the same private interfaces on other machines.

There is no login or deployment screen. Desktop browsers require one click to capture the mouse; mobile controls are immediately active. The browser receives an anonymous HttpOnly session cookie. Allegiance, ammunition, health, discoveries, salvage, position and current planet are saved in `data/universe.sqlite`. Territory ownership is saved under `data/<planet>/`. Keeping the cookie is necessary to return to the same identity. Earlier Meridian character files are imported on first connection. Existing faction allegiances are retained; old neutral saves receive a combat faction on reconnect without losing progress. All former Independent characters now receive a fighting allegiance without losing their inventory or position. Unclaimed is a territory state, not a player faction. The last selected respawn base is saved too.

After building, `npm run test:campaign:realtime` checks three isolated worlds with a maximum of 192 participants each, including any connected player, adaptive population bounds, and worker continuity. Add `--source-data data --browser-seconds 600` when running `node --no-warnings --experimental-sqlite scripts/campaign-realtime-check.mjs` to check a temporary copy of existing campaigns alongside a rendering browser. For repeatable CPU measurements, run `npm run profile:simulation`. The fixture saves a bundled baseline, V8 profile, timing report and checked state under `artifacts/`. See [simulation profiling](docs/PERFORMANCE.md) for parameters and the three-planet city-collision comparison.

## Play

- **WASD / mouse:** move and aim. **Space:** jump. **Double-tap a direction:** dodge, with the original air control and momentum.
- **Mouse / touch FIRE:** shoot. **R:** reload. **1–9, 0, wheel:** choose weapons.
- **E:** enter a vehicle, join a compatible crew, or open a nearby airlift pod's destination map. During pod travel, look around the cabin normally; it stays aligned with the route.
- **B / FIELD CAMP:** open construction, choose a module, rotate its preview and build ahead of you. Close the panel to move and aim.
- **Hold F / HOLD TO EXTRACT:** gather a nearby glowing xenolite seam on foot. Three seconds yields 12 salvage; the shared deposit regrows after three minutes. Moving, fighting or releasing cancels a partial extraction.
- **G / TACTICAL MAP:** open the full map while alive, inspect territory and battles, select your next respawn base, or change allegiance. Choosing a reinforcement point remembers it for your next death without moving you now. Zoom and drag to inspect an area; focus controls locate you, your last death, or a reported battle. **O:** star system and orbital travel. **M:** minimap and compass. **Tab:** scores. **T / Enter:** chat.
- **H:** toggle playtest hyperspeed (10× running speed and invulnerability). Press H again to return to normal; the HUD shows when it is active. No special URL is needed.
- Mobile has separate movement, look/fire, jump, dodge, weapon, reload and interaction controls.

Faction allies cannot damage each other; the other two factions are enemies. Wildlife, falls, drowning, lava and self damage still matter outside hyperspeed's test invulnerability. Capture a district or harbor by staying inside the flag's ring on foot at flag level. The capture panel shows distance to the ring, progress, time remaining, and any restriction preventing participation. Harbors use the walkable quay, not the submerged ferry berth.

One unopposed player needs **60 seconds** to claim neutral ground. A fully held enemy zone first takes **60 seconds to neutralize**, then **60 seconds to capture**. Enemy troops inside the zone pause all progress; leaving the zone pauses your contribution. Progress resumes from where it stopped. Human presence counts five times as much as a bot, and allies speed up capture to a maximum of three human equivalents. Neutralization and ownership changes produce on-screen announcements. Friendly controlled districts accelerate healing after combat. Switching factions requires leaving combat and waiting for the allegiance cooldown.

Each city, harbor and forward base has **three linked controls**. Holding **two** secures the base and unlocks reinforcements; taking one control shows exactly how many more are needed. Regional city controls are roughly **385–576 m apart**, while capital controls occupy districts **905–1,902 m apart**. Bots follow connected streets and the capitals' ground-level bridge networks. Capture boundaries never overlap, and only actual controls have world capture rings and flags. Control IDs remain stable so saved ownership survives the layout change. The world atlas colors control regions, and the star chart shows each planet's share of control points in the three faction colors, with unclaimed points in gray.

Infantry reinforcements arrive at a supported rally approach **at least 80 m outside every capture ring and 180 m from nearby enemies**. A threatened control cannot supply reinforcements until its approach has been clear for **12 seconds**. A different quiet owned control can still supply the base; if none is available, its map row explains the temporary block and another safe base or coastal reserve is used. Recent fighting also excludes nearby rally positions. These checks apply before neutralization and are repeated at the actual spawn, including for bots. Specialist boat and aircraft crews stage beside their vehicles when no enemy is nearby. The tactical map keeps partial and threatened bases visible, prioritizes your local city, and remembers your selected base while it is temporarily unavailable.

The respawn timer is **10 seconds**. First, a **1.8-second death camera** shows your body falling or carrying the lethal explosion's impulse; then the map opens for the remaining time. Select an available base or mobile rally jeep, or leave the choice automatic. A red cross marks your last death, including after respawn and reconnect. Recent fighting appears as fading battle areas with participating faction colors; reports expire after 30 seconds. A remembered spawn selection is reused; lost bases and destroyed vehicles are rechecked before spawning and safely fall back to an available point. A faction that loses every base retains coastal reinforcements for a comeback. If every approach is unsafe, deployment waits and checks again instead of placing you inside the fight. Initial arrival uses an available faction rally automatically. Spawn protection lasts three seconds and ends when firing or boarding a vehicle.

A stationary, sufficiently healthy friendly **jeep** becomes a mobile rally point away from friendly bases when its approach passes the same capture-zone, enemy-distance and recent-combat checks. Drive it forward, park, and let reinforcements spawn nearby. Live vehicle bodies block walking and swimming; supported hoods, roofs and decks can be stood on. Exits check neighboring hulls, and destroyed vehicles stop blocking movement. Driver and gunner are separate active seats on compatible vehicles; bots wait briefly for nearby friendly passengers, including humans. Boats follow ferry water lanes; aircraft crews operate real runway hulls and return for replacements after destruction. Ground transports unload near city fighting so infantry can reach the controls.

The default population target adapts between **96 and 192 per planet** (including humans), split across all three factions. Sustained load reduces safe distant reserves; twenty seconds of headroom permits gradual recovery. Nearby battles, vehicle crews and expeditions stay protected. Six-person squads share a base objective, assemble, use transport and airlift links for long travel, and assign reserves to threatened controls. Bots fight nearby dangerous creatures but do not choose creature raids as strategic objectives. Anti-air specialists hold a real rocket lock and space launches against each aircraft by at least seven seconds. Fighter hulls have 600 health and Nocturne bombers have 1,000; locked rockets use an aircraft-specific damage multiplier, so a healthy fighter survives two direct locked hits. Both seats receive escalating visual and audible acquisition, lock, and incoming-missile warnings, with relative bearing and estimated impact time. Aircraft missile guidance has a wider turning radius than ground-target guidance: a straight flight is vulnerable, while a timed bank can break the seeker. City arcades provide 4.6 m of clearance for ordinary tanks; bot drivers check their actual hull size before approaching overhead obstacles.

**Meridian** has shamblers, fast revenants and heavy plague brutes, plus the rare Ossuary Titan. **Cinder** has ash crawlers and the Cinder Colossus; **Nacre** has reef prowlers and the Tide Behemoth. Native fauna remain. Bosses have 12,000 to 15,000 health, visible health/name plates and recovery windows. Damaging a boss provokes faster pursuit up to **1,200 m** for **45 seconds**, refreshed by further hits. Bosses fire ranged blasts up to 950–1,100 m, with a fixed target marker, visible charging/projectile effects and an incoming-impact warning. Move out of the marked area or take solid cover; owned-base safe zones remain protected. Dead or departed attackers are forgotten. Bots still fight creatures they encounter without organizing creature raids.

Boss kills grant **500 salvage per qualifying hunter** for an Ossuary Titan, **650** for a Cinder Colossus and **600** for a Tide Behemoth. Eligibility requires at least 1% of the boss's maximum health in actual damage and a hit within the last two minutes; dying before the kill does not forfeit the bounty. Each kill leaves one shared, loaded **Nuke Launcher**, two ammunition crates and health at the corpse. Participants have **90 seconds** to claim the cache before it becomes public; the drops last five minutes. A planet-wide announcement credits the leading contributor and group. The map marks nearby weapon caches. Creature rosters, pursuit, attacks and reward definitions are selected by planet in `packages/shared/src/wildlife.ts`; unknown seeds use native fauna rather than inheriting zombies. Future terrain and ocean changes can supply their own ecology profile.

**M** shows a local tactical view with friendly/enemy contacts, available vehicles, hostile creatures, weapon caches, capture rings, your squad direction and last death. **G** adds named bases, capture status, faction borders, recent fighting and major-monster health/location reports; select an objective or monster report to focus it. Exact unit contacts come from nearby snapshots, while major-monster sightings are explicit planetary reports. Terrain detail is generated in the background, and live markers use bounded update rates.

Hostile creatures attack reachable vehicle hulls, including tanks and landed aircraft. Ordinary undead cannot strike aircraft flying overhead. Attacks damage armor once per hull rather than once per passenger.

`npm run test:campaign:browser` starts an isolated world and checks partial/secured/threatened reinforcement choices, live preference selection without teleporting, safe arrivals outside capture rings, ownership maps/bars, the death camera, death/battle markers, map zoom, remembered choices, lost-base fallback, and mobile-jeep destruction in desktop/touch layouts. `npm run test:aircraft:browser` checks actual server-derived acquisition, lock and incoming-missile warnings, including audio and both crew seats. `npm run test:creatures:browser` renders every creature model and boss warning in real WebGL on desktop and touch emulation.

`npm run test:capture:browser` checks live capture progress, contested/out-of-range pauses, ownership changes, harbor capture, and the H shortcut on an isolated server. It also checks the capture panel in desktop and touch layouts.

Each world retains the original 22.528 km square envelope (including ocean), four cities, cave networks, moving trains and ferries, launch pods, vehicle variants and ten infantry weapons. Discovering cities and extracting renewable xenolite award persistent salvage for field-camp modules. Deposits occur on supported gentle ground; their depletion and rewards survive reconnects and restarts. Crafting, trading and the wider economy remain outstanding.

Terrain, tree placement and grass share one climate model. Warm hills and rainforests remain green; cold regions and alpine summits retain snow, with conifers above the broadleaf frost line. Roads relocate flooded junctions and detour around lava and inland lake/river banks. Summit trails are omitted where volcanic basins replace the mountain. `npm run test:terrain:browser` captures warm hills, rainforest, snowy peaks and a repaired lava route using an isolated server, with desktop and mobile rendering checks. Restart the dev server and refresh the browser after updating shared world generation.

Build outside cities and away from roads and transit stops. A **trail shelter costs 20 salvage**, a **medical station 25**, and an **ammo fabricator 30**. Shelters have a ramp, deck, roof and solid cover. Within 5 m and with a clear line of sight, medical stations add 6 health per second and fabricators replenish ordinary weapon reserves after combat. Services support the owner and players matching the module's allegiance when built; legacy unclaimed modules still support their original owner. Rare ammunition still requires exploration.

Modules and their payments are saved together in the universe database. They remain after logout, restart and planetary travel. Each character may own six modules across the universe; each 128 m cell allows four. Owners can pack modules from nearby after everyone steps clear; packing does not refund salvage. This construction system uses the default universe launcher. The legacy standalone mode has no construction service. Modules currently have no destruction, decay, respawn binding or distant atlas markers.

Open the star chart from the HUD or with **O**, choose a planet, and mark the nearest transit pod. Reach that physical pod on foot to launch. The 5-second charge cancels when you move, take damage or board a vehicle. A committed launch automatically reconnects you at the destination's spaceport with your supplies and discoveries. Ordinary connection interruptions also reconnect automatically; opening another tab intentionally closes the older session.

## Current implementation and verification

- Original 60 Hz shared movement, prediction/reconciliation, dodge, air control, lag compensation, terrain streaming and transit physics retained.
- Automatic desktop/mobile arrival with a randomly assigned combat faction; full-world atlas with optional allegiance changes; objective-seeking AI and capture at city districts and harbors.
- Three world processes, gateway routing, SQLite character ownership, epoch-fenced checkpoints, destination reservations and idempotent transfers. The source character stops simulating before its transfer commits. Workers pause simulation when coordinator authority expires.
- World-worker supervision, automatic browser reconnect and tested recovery after a worker crash. Private HTTP/WS addresses allow placing workers on other machines; see [DEPLOY.md](DEPLOY.md).
- Protocol 28 carries persistent simulation time, safe-integer entity references, authoritative base teleporter layouts, bounded resource snapshots and committed boss attack timing. Characters keep their database ID through reconnects, restarts and planetary travel. Coordinated workers reserve durable ID batches that are never reissued, protecting hulls and projectiles that outlive their source worker elsewhere. Existing saves migrate automatically; clients, workers and coordinator must update together.
- Persistent planetary clocks and durable world authority epochs. Workers initialize time before admission, retain bounded simulation debt, and restart safely when they cannot catch up. ## Full objective remains active

This implementation is not yet the completed massively distributed game. It runs one authority per planet, with a default admission limit of 64 humans per planet. Bots fill an adaptive target of 96–192 participants and step aside as humans join. The gateway and SQLite coordinator share one process. Neither these limits nor the spatial index are **evidence of 100,000-player capacity**.

Outstanding work includes geographic regions within popular planets, neighbor simulation and vehicle handoff, coordinator throughput/availability at scale, spherical traversal, expanded construction, survival and a broader crafting and trade economy, larger passenger transports and deeper logistics, richer alien art and encounters, physical-mobile profiling, and realistic load/soak/failure testing. Surfaces remain bounded planar regions; orbital globe portraits do not imply spherical traversal. See [ARCHITECTURE.md](ARCHITECTURE.md) and [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md).

See [DEPLOY.md](DEPLOY.md) for Node, Docker and systemd setup. Production hosting, domain configuration and an automated release/update workflow remain separate deployment steps.
